# desktop-tutorial

Kişisel proje deposu (GitHub Desktop tutorial kökenli). Aşağıdaki uygulamalar birbirinden bağımsız Next.js klasörleridir.

| Klasör | Açıklama | Port |
|--------|----------|------|
| [`live-translate/`](live-translate/) | Canlı İngilizce → Türkçe altyazı (mikrofon + çeviri) | 3456 |
| [`username-finder/`](username-finder/) | Türkçe kullanıcı adı arama — çoklu platform profil taraması | 3457 |

## Hızlı başlatma (Windows)

- `live-translate\sunucu.bat` — çeviri sunucusu
- `username-finder\sunucu.bat` — kullanıcı adı arama

## Canlı site (GitHub Pages)

[`live-translate`](https://qquaq.github.io/desktop-tutorial/) — yalnızca `live-translate` statik yayını (`docs/`).

`username-finder` şu an yerel veya [Vercel](username-finder/README.md) ile dağıtım içindir; ayrıntılar için `username-finder/README.md`.
